# Cozy Ponto

Um controle de ponto minimalista e aconchegante, com visual inspirado no Notion, para registro de jornada de trabalho, organização de tarefas diárias e cálculo automático de horas extras.

## ✨ Funcionalidades

- **Registro de jornada** — marque entrada, saída para almoço, retorno e saída do expediente com poucos cliques.
- **Cálculo de horas extras** — cálculo automático do total de horas trabalhadas no dia/semana/mês e das horas excedentes em relação à jornada padrão.
- **Tarefas diárias** — crie e acompanhe uma lista de tarefas do dia junto ao seu registro de ponto.
- **Interface estilo Notion** — visual limpo, minimalista e aconchegante, com foco em simplicidade e produtividade.
- **Histórico de registros** — consulte dias e períodos anteriores para acompanhar sua jornada ao longo do tempo.

## 🚀 Como rodar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) (recomendado LTS mais recente)
- npm (instalado junto com o Node.js)

### Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/atlas436/notion-ponto-app.git
   cd notion-ponto-app
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Abra o navegador no endereço exibido no terminal (geralmente `http://localhost:5173` ou `http://localhost:3000`, dependendo da stack utilizada).
